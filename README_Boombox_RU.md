# JBL YouTube Boombox 3.5.0

Полностью закройте игру. Распакуйте WinRAR/7-Zip папку BepInEx с заменой.
Полный ZIP содержит DLL, yt-dlp, Deno и FFmpeg; ZIP использует LZMA.
Всем в коопе нужны 3.5.0 и новое лобби. Не оставляйте дубликаты DLL.

Музыка идёт из колонки через FMOD: рядом громко, вдали затухает, за пределом
дистанции не слышно. Пространственный режим автоматически включается
и в старом конфиге. Audio.Volume = 0.7, Audio.Distance = 35 метров по умолчанию;
порог полной громкости 2.5 м, затем линейное затухание.

Insert создаёт колонку у хоста; E — взять, Q — бросить, ЛКМ — музыка.
Поиск по имени/исполнителю/ссылке. Физика и обводка сохранены.
Поток yt-dlp → FFmpeg stdin, повтор при 403, таймеры загрузки и диагностика FMOD
сохранены. Возрастные/закрытые ролики могут требовать входа; выбирайте публичные.

В общем PriorityFixes архиве находятся обновления DLL; папка tools от 3.4.0
должна уже стоять. Отдельный Boombox_3.5.0.zip содержит полный комплект.
79 целевых проверок и регрессия прошли; живой звук/кооп Windows здесь не запускались.
