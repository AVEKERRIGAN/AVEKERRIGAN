# JBL YouTube Boombox 3.1.0 — бросок и загрузка музыки

## Обновление

Закройте игру. Распакуйте папку BepInEx из `Boombox_Update_3.1.0.zip`
в папку игры с заменой `BepInEx/plugins/Boombox/Boombox.dll`.
Это маленькое обновление для уже установленной 3.0.0; помощники в него не входят.

Для полной установки нужны **оба** архива:

- `Boombox_3.1.0.zip` — DLL, yt-dlp.exe и ffmpeg.exe.
- `Boombox_YouTube_Runtime.zip` — deno.exe, необходимый хосту для YouTube.

После распаковки в `BepInEx/plugins/Boombox/tools/` должны быть
`yt-dlp.exe`, `ffmpeg.exe`, `deno.exe`. В игре уже должен быть BepInEx 5.
Оставьте одну актуальную Boombox.dll; копии старых DLL из других папок удалите.
В журнале загрузки будет `JBL YouTube Boombox 3.1.0`, сообщения помечены `[JBL31]`.

**Для коопа обновите мод у хоста и всех пользователей бумбокса до 3.1.0,
перезапустите игру и создайте новое лобби.** Протокол сообщений обновлён:
версии 3.0.0 / 3.1.0 смешивать нельзя. Игрокам без мода музыка не передаётся.

## Бросок

Insert — создать колонку, E — взять, Q — бросить, ЛКМ — меню музыки.

Q теперь передаёт хосту положение камеры и направление взгляда.
Колонка выпускается перед камерой на высоте рук, получает скорость
7.5 м/с по взгляду, небольшой подъём, часть скорости игрока и вращение.
Хост считает гравитацию и столкновения через Rigidbody / BoxCollider.
Материал имеет трение и небольшой отскок. Перед стеной место выпуска
ограничивается проверкой пространства. У остальных игроков движение сглаживается.
Бросок не останавливает играющую музыку.

Сила броска: `Physics.ThrowSpeed` (4..12) в
`BepInEx/config/com.malenki.boombox.cfg`. Новая модель не заменяется:
используется тот же JBL, без патчей штатных Bongo / Item.

## Музыка

Поиск по названию, исполнителю или ссылке YouTube. Выбранный звук извлекает
и декодирует **хост**, затем передаёт участникам с модом. По умолчанию музыка
слышна всем таким игрокам; пространственный звук включается через `Audio.SpatialAudio`.
Громкость каждого игрока задаётся `Audio.Volume`.

Исправлено:

- Команды yt-dlp / ffmpeg получают явную, экранированную строку Arguments,
  совместимую с Unity Mono, вместо ArgumentList.
- Передаются заголовки User-Agent / Referer из ответа YouTube, когда они есть.
- Ошибки помощников сохраняются и показываются в меню и логе.
- Статусы меняются: получение ссылки → подключение → играющий звук / ошибка.
  Состояние «Играет» выставляется после прихода первого звукового пакета.
- Поиск ограничен 25 секундами, получение ссылки — 30, начало звука — 15.
  После начала поток прерывается с ошибкой, если не отвечает 12 секунд.
  Это пределы ожидания, а не обещание загрузки за указанное время.
- Отмена и завершение помощников выполняются в фоновых потоках.
  Результат старого запроса не останавливает новый трек.
- Ошибка отсутствующего deno.exe или другого помощника теперь видна;
  надпись «Загрузка звука…» не остаётся навсегда после неудачи.

Если хост не имеет доступа к YouTube или видео требует входа / недоступно,
в меню появится причина. Мод не обходит ограничения сайта и сети.
Если загрузка не удалась, нужна свежая `BepInEx/LogOutput.log` с `[JBL31]`:
старые присланные журналы относятся к 1.1.9 / 1.1.10 / 2.0.0.
Подписанные URL и значения cookie скрываются из диагностических сообщений.

## Что проверено

Сборка против предоставленных DLL Unity / игры / BepInEx: без ошибок и предупреждений.
60 целевых проверок: направление и скорость, недопустимые координаты,
сериализация взгляда / скоростей / статусов Mirror, реальные запуски процессов,
пути с пробелами и кириллицей, поиск, тайм-ауты всех стадий, отмена,
ошибки и декодирование настоящим FFmpeg в PCM 24 kHz mono.
Дополнительно прошли 223 351 регрессионная проверка математических движков,
аудиобуферов и протоколов.

Живой YouTube из облачной среды возвращает proxy 403, поэтому его воспроизведение
здесь не подтверждено. Физический бросок и звук в настоящей Windows-игре,
а также два игрока в коопе здесь не запускались. Это исправленная сборка для
проверки в игре; прохождение офлайн-проверок не заменяет игровой проверки.
