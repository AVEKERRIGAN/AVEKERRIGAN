# JBL YouTube Boombox 3.4.0

Закройте игру. Распакуйте WinRAR/7-Zip папку BepInEx в папку игры с заменой.
ZIP LZMA; DLL, yt-dlp, Deno и FFmpeg включены. Всем в коопе — одна версия и новое лобби.
Оставьте одну копию Boombox.dll. Запуск версии виден в LogOutput.log: [JBL34].

В 3.4 звук направлен через FMOD — аудиосистему игры. Unity AudioSource
оставлен как запасной путь при ошибке FMOD. Хост получает PCM напрямую;
сетевое эхо фильтруется по последовательности. Конец трека ждёт буфер.
В логе пишутся создание потока FMOD и число запрошенных им PCM-сэмплов.

Сохранено из 3.3: звук скачивает yt-dlp и передаёт байты в FFmpeg через stdin.
При 403 выполняется новое извлечение альтернативным клиентом, не более двух
повторов до первого PCM. Возрастные и закрытые ролики могут требовать входа
в YouTube; выбирайте доступные публичные ролики.

Insert создаёт колонку у хоста, E берёт, Q бросает в направлении взгляда.
ЛКМ открывает музыку. Поиск по исполнителю, названию или ссылке YouTube.
Размер +25%, контур при наведении, бросок и физика сохранены.

Конфиг com.malenki.boombox.cfg: Audio.Volume (по умолчанию 0.7), Distance,
SpatialAudio (false — общий звук; true — по расстоянию), Model.Scale, Physics.ThrowSpeed.
Загрузка каждой попытки ограничена 18 секундами; общая защита — 60 секунд,
поток без данных останавливается через 12, поиск — 25.

Проверены сборка, реальные FFmpeg/PCM-процессы, повтор 403, ошибки/таймеры,
сериализация и PCM для FMOD. Windows-аудиоустройство, живая игра и кооп
в этой среде не запускались; YouTube в облаке блокируется proxy 403.
