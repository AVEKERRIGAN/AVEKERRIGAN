В режиме auto выбирается поддерживаемый браузер Windows по умолчанию:
Chrome, Edge, Opera/GX, Яндекс, Brave, Vivaldi, Chromium. Для другого движка,
например Firefox, используется установленный поддерживаемый браузер.
Профили телефона разделены по браузерам; имя выбранного видно в настройках.
Browser.Selection и Browser.ExecutablePath позволяют выбрать браузер вручную.

В TikTok / Reels колёсико переключает ролики через штатную навигацию;
комментарии листаются в своём списке. Исправлены масштаб / привязка страницы,
очередь повторных жестов и первый кадр при повторном открытии телефона.
Модель Pro Max, хват рук и управление сохранены: P — телефон, ПКМ — просмотр,
E — спин. При обновлении нужно заменить **оба файла — DLL и PhoneBrowser.exe**.

220 проверок пройдены с настоящим Chromium и локальными тестовыми страницами.
Windows, его реестр, реальные Opera/Яндекс и живой TikTok здесь не запускались.
Предыдущие версии сохранены в downloads.

Закройте игру. Сохраните старые моды и удалите дубликаты DLL. Распакуйте папку BepInEx в игру с заменой файлов. Для бумбокса нужны ОБА его архива. У всех участников коопа должны быть одинаковые версии; перезапустите игру и создайте новое лобби.

Бумбокс: Insert — создать, ЛКМ — музыка, E — взять, Q — бросить, Escape — закрыть меню. Поиск по названию или ссылке YouTube; выбранный звук передаёт хост всем игрокам.
