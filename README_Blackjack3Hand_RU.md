# Blackjack 3-Hand 1.5.0

Полностью закройте игру и распакуйте BepInEx в папку игры с заменой.
Оставьте одну копию Blackjack3Hand.dll. Всем участникам нужна 1.5.0 и новое лобби.
Перезапуск нужен и для восстановления шрифта, который могла удалить предыдущая версия.

Исправлена сумма $0: в сети передаются мантисса и показатель BigNumber, а не
сокращение вроде 195K. Ставки, DOUBLE и SPLIT показываются в каждой руке,
на кнопках и мониторе; личный итог считает только ваши руки.

Во время игры можно выбирать любую свою незавершённую руку (например, 2 → 3 → 1).
HIT/STAND/DOUBLE/SPLIT не требуют ожидания первой руки. У раздвоенной руки
действия идут на её первую незавершённую часть. DOUBLE допустим при двух картах;
SPLIT — при паре. В коопе каждый управляет своими руками. После всех STAND,
двадцати одного или BUST играет дилер. Таймер — 20 секунд без действия;
каждое действие продлевает ожидание, затем оставшиеся руки автоматически STAND.

Стол и панель ниже: Layout.HeightMultiplier = 0.78. Ширина сохранена.
Круглые стопки фишек, закрывавшие очки, убраны. Общий запасной шрифт игры
больше не удаляется. Неактивные столы исключены из обновления; глобальная
проверка клавиатур выполняется раз в секунду, тексты — 10 раз в секунду.

В BepInEx/config/com.malenki.blackjack3hand.cfg можно настроить HeightMultiplier
(0.6..1) и TableScale. Для коопа значения должны совпадать; создайте новое лобби.

Проверены сборка, настоящий денежный тип игры (включая пример 195K из лога),
сетевой кодек, владельцы, ставки и порядок действий. Живая Unity-сцена,
смена дня и реальные совместные партии в этой среде не запускались.
