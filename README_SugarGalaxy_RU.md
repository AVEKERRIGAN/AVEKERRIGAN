# Sugar Galaxy 1.2.17

В старых кадрах взрыва было нарисовано X25 — поэтому поверх настоящего X3
появлялся посторонний множитель. Эти кадры больше не используются для бомб.
Взрыв выполнен кольцом/искрами без цифр; улетающее значение собирается из
той же золотой таблицы символов, что надпись на самой бомбе. Порядок X3 / X25
и стиль едины; значение берётся из результата хоста. Математика сохранена.

Полностью закройте игру и замените BepInEx. Всем в коопе нужны одинаковые
версии и новое лобби. Базовый BepInEx и другие слоты уже должны быть установлены.
Сборки, данные и тесты проверены; живая Unity-сцена/настоящий кооп не запускались.
